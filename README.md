# Spotify Spark Engineering

A data engineering project focused on learning and applying **Apache Spark** with Spotify data.

The project covers data ingestion, cleaning, transformation, analysis, feature engineering, and machine learning using **PySpark**.

## 🎯 Project Goals

* Learn and practice Apache Spark and PySpark.
* Process and transform large datasets.
* Build data engineering pipelines.
* Perform exploratory data analysis using Spark.
* Create features for machine learning.
* Experiment with machine learning models using Spark MLlib.

## 🛠️ Technologies

* Python
* Apache Spark
* PySpark
* Spark SQL
* Spark MLlib
* Pandas
* Jupyter Notebook
